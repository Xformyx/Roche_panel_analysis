Baseline 분석 파라미터

모든 오더(Baseline / Germline / Followup / Longitudinal)의 표준 FASTQ → BAM → VCF 분석에 적용됩니다.

A. UMI 모드  (fgbio)
체크 시 UMI consensus 파이프라인 수행. 미체크 시 표준 BWA + Picard MarkDuplicates 사용.
오더 등록 시 개별 지정으로 오버라이드할 수 있습니다.
기본값 3M3S+T 3M3S+T = KAPA UMI adapter (R1/R2 각각 3 bp UMI + 3 bp skip + 나머지 template)
B. Variant Calling  (VarDict)
최소 변이 Allele Fraction (기본 0.5%)
오더 등록 시 개별 지정도 가능합니다.
C. 서브샘플링  (seqtk)
FASTQ 파일 크기가 임계값 초과 시에만 서브샘플링 수행 (원본 파일 보존)
이 크기 이상이면 서브샘플링 수행
UMI 추출 후 raw read pair 수 기준 (UMI 디듀플 전)
동일 Seed = 재현 가능한 서브샘플링
D. Adapter Trimming  (fastp)
-g poly-G   -W 5 슬라이딩 윈도우   -q 20 최소 품질   -u 40 최대 불량 %   -l 75 최소 길이   -c 염기쌍 보정
E. Consensus Read Filtering  (fgbio FilterConsensusReads — UMI 모드 전용)
UMI 패밀리 최소 Read 수 (1 = Singleton 허용)
Consensus 염기 최소 Quality
Read 전체 최대 오류율 (기본 2.5%)
단일 염기 최대 오류율 (기본 10%)
최대 No-call 비율 (기본 10%)

RNA 분석 파라미터 (RNAseq Pipeline)

RNA 파이프라인 실행 시 STAR Index, GTF, BED12, CTAT Library 경로를 지정합니다. 비워두면 nextflow.config의 genomes 블록에서 자동 해석합니다.

STAR --genomeDir 에 전달되는 인덱스 디렉토리. 비워두면 nextflow.config genomes 블록의 star_index 값 사용.
featureCounts 유전자 열거에 사용하는 GTF 열거 파일.
RSeQC (TIN, read distribution 등)에 사용. 비워두면 RSeQC 단계를 건너맙니다.
RNA에는 -l 50 (최소 50bp) 권장. ctDNA는 -l 75 사용.
STAR-Fusion 실행에 필요한 CTAT Genome Library 경로. 비워두면 Fusion 검출 단계를 건너뜁니다.
다운로드: Broad Institute CTAT resource lib
STAR Index 생성 명령 (hg38 예시):
STAR --runMode genomeGenerate \ --genomeDir /work_nxt_data/refs/hg38/star_index \ --genomeFastaFiles /work_nxt_data/refs/hg38/ucsc.hg38.fasta \ --sjdbGTFfile /work_nxt_data/refs/hg38/genes.gtf \ --runThreadN 16
BED12 변환 (선택사항):
gtfToGenePred genes.gtf genes.genePred && genePredToBed genes.genePred genes.bed12

RNAseq 분석 파라미터

STAR 정렬 → featureCounts 정량 → 발현량 시각화 → MultiQC 파이프라인이 실행됩니다. 레퍼런스 경로는 설정(Setup)에서 지정하거나 nextflow.config의 genomes 블록에서 자동 해석됩니다.

STAR Index & GTF 경로는 설정(Setup) → RNA 분석 파라미터 탭에서 설정합니다. 설정하지 않으면 nextflow.config의 genomes 블록 경로를 자동 사용합니다.
-l 50 최소 리드 길이   -q 20 최소 품질   -c 페어 교정
파이프라인 단계
1. FastQC — 원시 리드 QC
2. fastp — 어댑터 트리밍
3. STAR — 스플라이스 정렬 (2-pass)
4. samtools — 정렬 통계
5. RSeQC — RNA-seq 특화 QC
6. featureCounts — 유전자 정량
7. 발현량 시각화 — CPM/TPM 플롯
8. MultiQC — 통합 QC 리포트
